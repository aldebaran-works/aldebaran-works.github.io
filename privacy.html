プライバシーポリシー

Aldebaran Works（以下「当事業者」）が運用するバックアップツール（rclone を使用し Google Drive に接続するもの。以下「本ツール」）における情報の取り扱いを定めます。

1. 利用者

本ツールは当事業者が自社の業務データをバックアップするためだけに使用するもので、第三者への提供・公開はしていません。

2. アクセスする情報

本ツールは Google Drive API の drive.file 権限のみを使用し、本ツール自身が作成したファイルにだけアクセスします。それ以外の Google アカウントの情報やファイルにはアクセスしません。

3. 利用目的

当事業者の業務ファイルを暗号化したうえで Google Drive に保存し、必要なときに復元するためにのみ使用します。

4. 第三者提供

取得した情報を第三者に提供・販売・共有することはありません。Google から取得した情報の利用は Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

5. 保存と削除

認証情報は当事業者のPC内にのみ保存します。Google アカウントの「サードパーティ製のアプリとサービス」からアクセス権をいつでも取り消せます。
